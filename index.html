Usage instructions:

Provide query parameters in the URL to generate a password.
If no parameters are provided, you will see this instruction page.

Parameters:
- length: integer (e.g., 16)
- uppercase: true or false
- lowercase: true or false
- numbers: true or false
- special: true or false
- format: "json" (optional, outputs result as a JSON string)

Example Usage:
?length=16&uppercase=true&lowercase=true&numbers=true&special=true&format=json
